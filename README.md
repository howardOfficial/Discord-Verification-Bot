# Discord-бот: Верификация участников

Демонстрационный бот для выдачи ролей и скрытых ответов.
Функции: Кнопка «Проверить статус», выдача роли @Verified, скрытые ответы (ephemeral), отправка ЛС.
Стек: Python, discord.py.

Как запустить:

1. Установите зависимости: pip install -r requirements.txt
2. Вставьте свой токен в переменную TOKEN и ID роли в VERIFIED_ROLE_ID.
3. Запустите: python bot.py
4. В канале Discord напишите !setup_verify, чтобы отправить сообщение с кнопкой.

Код можно адаптировать под любые задачи: таймеры, напоминания, автовыдача ролей по событиям.
